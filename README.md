# Atom-Parser

1) Atom Parser V2
   A basic calculator for calculating the proton, neutron, and electron count and location from an element's atomic number and weight, it uses a predefined dictionary             labelling the shell (or subshell I don't know the exact language) that goes something like this ``{'1s': 2}``, and a for loop on the dictionary to make a new dictionary        that represents the notation of the electron configuration, also has a separate ``read()`` function to convert the electron config dictionary into a readable string
